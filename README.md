# Electric Vehicle Analysis Dashboard | Power BI

## Overview
Analysed 150,000+ electric vehicle records across the US market to uncover adoption trends, market share, and regional patterns.

## Key Findings
- BEVs dominate with 77.6% market share vs PHEVs at 22.38%
- EV adoption increased sharply post-2020
- Tesla leads by volume, followed by Nissan and Chevrolet
- Average electric range: 67.86 miles

## Tools Used
- Power BI (DAX, Data Modelling, Interactive Dashboard)
- Data Cleaning and Transformation
- Data Visualization and Storytelling
